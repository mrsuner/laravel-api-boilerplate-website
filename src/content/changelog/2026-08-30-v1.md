## Stable distribution

- Laravel API Boilerplate is available as a GitHub Template, a Git clone, and `composer create-project mrsuner/laravel-api-boilerplate "^1.0"`.
- `mrsuner/laravel-api-keys` and `mrsuner/laravel-coupon` are available as stable Composer packages for Laravel 12 and 13.
- Every component has an immutable `v1.0.0` Git tag, a GitHub Release, an MIT license, and reproducible CI gates.

## Installation

```bash
composer create-project mrsuner/laravel-api-boilerplate my-api "^1.0"
composer require mrsuner/laravel-api-keys "^1.0"
composer require mrsuner/laravel-coupon "^1.0"
```

See the [installation guide](./docs/installation) and official package documentation for configuration and integration details.
